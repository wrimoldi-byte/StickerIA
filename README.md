# StickerIA 0.2 — prototipo Android

Buscador **integrado** de imágenes a través de la API pública de Wikimedia Commons (la búsqueda incluye la palabra "sticker"). No se necesita cuenta de Telegram ni cuenta en la aplicación.

## Disponible
- Buscar imágenes desde la pantalla de StickerIA, sin abrir Google.
- Ver miniaturas y el archivo de origen.
- Guardar una copia en el almacenamiento privado de la aplicación (todavía no se puede exportar desde la interfaz).
- Compilación automática con GitHub Actions.

## Pendiente
- Búsqueda integrada de paquetes públicos de Telegram y otros catálogos.
- Conversión estática y animada a paquetes WEBP para WhatsApp.
- Exportación nativa de paquetes a WhatsApp.
- Generación de stickers con IA y favoritos.
- Presentar autor y licencia de forma detallada para controlar su reutilización antes de republicarlos.

**Importante:** Las imágenes de Commons no tienen todas la misma licencia. Verificá los términos de cada imagen y su atribución en la fuente.

Abrí Actions > Compilar APK StickerIA > ejecución exitosa > Artifacts > StickerIA-APK.
