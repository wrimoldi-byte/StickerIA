# StickerIA

Proyecto Android inicial. GitHub Actions compila automáticamente una APK de prueba.

## Funciones disponibles
- Pantalla de búsqueda que abre resultados de imágenes en el navegador.
- Apertura de enlaces públicos a paquetes de stickers de Telegram (sin inicio de sesión en StickerIA).

## Pendiente
- Búsqueda integrada multifuente y Telegram desde backend.
- Conversión real a WEBP y exportación a WhatsApp.
- Generación con IA.
- Revisión de permisos y licencias de los contenidos.

## Descargar APK
Abrí la pestaña Actions, elegí la ejecución más reciente de **Compilar APK StickerIA** y descargá el artefacto **StickerIA-APK**. La APK es de desarrollo, no una versión de producción.

Proyecto mínimo compilable con Kotlin, Gradle y GitHub Actions.
